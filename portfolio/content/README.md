# Contenido histórico de migración

`home.json` y `about.json` fueron trasladados a los borradores reales de Sanity. El frontend ya no los importa ni los usa como sustitución del CMS.

Se conservan como entrada reproducible de la migración, no para ediciones rutinarias. Las próximas ediciones deben hacerse en Sanity. Volver a ejecutar `sync-editorial-drafts.mjs --apply` reemplaza los textos equivalentes y genera un respaldo previo; no debe ejecutarse para actualizar el sitio normalmente.

Consulta `../CMS-INTEGRATION-REVIEW.md` para los IDs, las copias y la verificación.
